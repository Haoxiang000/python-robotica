# Actividad 37 — Mayúsculas y minúsculas

- *Módulo*: 6 · Operaciones con cadenas
- *Fecha límite de entrega*: domingo 22 de noviembre de 2026, 23:59
- *RA 1*: e) Se ha modificado el código de un programa para crear y utilizar variables.

## Contexto

`upper()` pasa un texto a mayúsculas. `lower()` lo pasa a minúsculas. El texto original no cambia: cada método devuelve uno nuevo.

## Objetivo

Mostrar una orden en mayúsculas y en minúsculas.

## Lo que debes hacer

1. Crea `solucion/mayusculas.py`.
2. Declara `orden = "Adelante"`.
3. Muestra el resultado de `orden.upper()`.
4. Muestra el resultado de `orden.lower()`.
5. Muestra también `orden`, para ver que sigue igual.
6. Ejecuta el programa y guarda la salida en `solucion/mayusculas-salida.txt`.

## Entregable

- `solucion/mayusculas.py`.
- `solucion/mayusculas-salida.txt` con la salida de la consola.

## Criterios de evaluación

| Criterio | Peso |
|---|---|
| Se muestra el resultado de `upper()` | 30 % |
| Se muestra el resultado de `lower()` | 30 % |
| Se muestra la orden original, sin cambiar | 20 % |
| La salida está guardada en `mayusculas-salida.txt` | 20 % |

## Pista de cara al futuro

Hay que imprimir lo que devuelve el método. Si solo escribes `orden.upper()` y no lo muestras, no verás el cambio.
