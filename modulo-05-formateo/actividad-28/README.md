## Contexto

En la misma frase caben varios datos. Cada uno va entre sus llaves.

## Objetivo

Meter el nombre del robot y el número de ruedas en una sola frase.

## Lo que debes hacer

1. Crea `solucion/ficha.py`.
2. Declara `nombre = "Titán"` y `ruedas = 4`.
3. Muestra una sola línea con un f-string que incluya `nombre` y `ruedas`. Por ejemplo: `f"El robot {nombre} tiene {ruedas} ruedas"`.
4. Ejecuta el programa y guarda la salida en `solucion/ficha-salida.txt`.

## Entregable

- `solucion/ficha.py`.
- `solucion/ficha-salida.txt` con la salida de la consola.

## Criterios de evaluación

| Criterio | Peso |
|---|---|
| La frase es un f-string | 30 % |
| La frase incluye el nombre y el número de ruedas | 50 % |
| La salida está guardada en `ficha-salida.txt` | 20 % |
